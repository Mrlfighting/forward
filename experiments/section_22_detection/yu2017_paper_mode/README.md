# 于生宝等（2017）第二章识别规则验证

本目录只验证原文第二章的静态效应识别。输入为已经保存的 TM 视电阻率；不调用 SimPEG，不做静态校正、反演或跨频最终测点分类。现有 `detect_static_sites`、旧 2.2.1 结果和 2.3 反演入口均保持原样。

## 原文规则与本项目明确选择

| 环节 | 本入口行为 | 依据或限制 |
| --- | --- | --- |
| 空间信号 | 每个频率的原始 `rho_a(x, f)` | 于生宝等（2017）第二章处理视电阻率；本入口不取对数 |
| 小波 | 一阶高斯导数、`1/√a` 归一化 | 原文未给唯一母小波；这是用户已确认的具体选择 |
| 极大值 | 各尺度非零局部模极大值，保留符号 | 识别阶段不使用第三章的校正阈值 |
| 传播 | 大尺度向小尺度；同位置同符号优先，否则在原文限定区间按式（9）选模值差最小点 | 使用现有已测数学模块 `tracking.py` |
| 指数 | 每条完整传播线保存所有相邻二进尺度 `alpha_j`；逐对标记 `alpha_j<0` | 不把多个值合成单一整线指数 |
| 位置 | 完整传播线的最小尺度端点；最近原测点仅为诊断字段 | 不定义映射距离阈值或跨频投票 |
| 插值、尺度、边界 | 线性插值至 512 点；`2,4,8,16,32`；`reflect` | 用户明确沿用本项目五尺度验证设置；不是原文 H08 的三次样条、八尺度示例 |

因此这里严格执行的是**原文明确给出的识别步骤**。原文未公开的数值选择已记录在 `configs/section_22/yu2017_paper_mode.json`，不得将它们表述为原文规定，也不得把本次结果说成 H08 原始数值复现。

## 运行

```powershell
& 'D:\SoftwareInstallation\Anaconda\envs\mt-static-rebuild\python.exe' 'D:\MT_StaticShift_Inversion\experiments\section_22_detection\yu2017_paper_mode\run.py'
```

可以用 `--case s2_41_stations` 只运行一个配置中的场景。输入 SHA256 在读取时检查。六组固定对照包括 41 点 S0/S2、同一数据的 8 点子集，以及四浅部体场景的有／无浅部体 41 点输入。8 点子集只是空间采样诊断，不是新增正演。

每组输出于 `results/section_22/yu2017_paper_mode/<case_id>/`：`diagnostics.npz` 保留原始视电阻率、插值剖面、小波系数、逐尺度模极大值；`maxima_lines.json` 保存完整和被剔除的传播线及每对 α；`negative_alpha_pairs.csv` 是逐频负指数证据；`summary.json` 保存输入哈希、证据计数和仅供评价的真值邻域统计；`逐频负指数证据.png` 用于人工核查。根目录 `comparison.json` 汇总所运行场景。

## 固定参数验证结果

41 点 S0 和四体无浅部体对照均无负 α 证据。41 点 S2 的两处目标在最近原测点各有 8/20、10/20 个频率出现负指数证据；四浅部体的四处目标各为 7/20、7/20、5/20、7/20。两类正例都有邻站和少量远处证据，故这些数字**只支持目标邻域存在静态效应特征，不支持自动唯一分类**。

将同一 S2 正演抽取为 8 个反演测点时，两目标均无对应证据，五个负 α 证据全部出现在右侧约 8～10 km。该失败不能通过把真值测点填入识别结果或改变已固定尺度、阈值来掩盖；说明当前配置及稀疏采样下，原文逐频规则不能直接提供反演所需的可靠静态点掩码。
