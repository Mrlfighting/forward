## 必须保持的科学定义

1. 静态全数据反演：所有测点使用 `rho_a + phase`。
2. 相位保留法：普通点使用 `rho_a + phase`；已判定静态点仅使用 `phase`，不使用其 `rho_a` 绝对幅值。
3. 形态约束法：在相位保留法基础上，静态点额外使用去除频率无关常数对数幅值的 `rho_a shape`；不得重新引入静态点的绝对视电阻率。
4. 静态点完全丢弃：静态点的 `rho_a` 与 `phase` 均不使用，仅用于消融对比。

形态约束的既有方法定义与历史实验细节见项目根目录的 `项目阶段性成果与问题_记忆迁移.md`。该文件作为既有研究记录保留；后续的新进展、决策、问题和验证结果同步记录在 `memory/` 对应文件中。

## 已有结果的解释边界

- 相位保留法是稳定基线；shape 是有条件的补充信息，并非普遍优于相位保留法。
- 当前数值结果中，shape 的明显优势主要见于目标敏感相位信息缺失、削弱或被合理降权的情形。
- 当前 L4 实测中 shape 改善有限，既不能写成普遍优于相位保留法，也不能据此断言方法普遍无效。
- 静态效应识别仍是主要不确定性来源。
- 不同方法的数据数量和目标函数不同，不能单凭较低 WRMS 或 `phi_d/N` 证明方法更好。
